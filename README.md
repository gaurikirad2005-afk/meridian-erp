# NexaFlow ERP – Enterprise Resource Planning System

NexaFlow ERP is a web-based Enterprise Resource Planning (ERP) application designed to manage business operations through a centralized platform.

## Features

- **Dashboard:** Business overview and key statistics.
- **CRM:** Manage companies, contacts, leads and deals.
- **HR Management:** Employee, department and payroll management.
- **Inventory:** Products, warehouses and stock movements.
- **Accounting:** Invoices, expenses and financial records.
- **Procurement:** Vendors, purchase orders and requisitions.
- **E-commerce:** Product catalog, shopping cart and orders.
- **Project Management:** Projects and task tracking.
- **Customer Support:** Support tickets and knowledge base.
- **Reports:** Business reports and data exports.
- **User Management:** Role-based access and permissions.

## Technology Stack

- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- Thymeleaf
- HTML, CSS and JavaScript
- H2 Database
- Maven

## Run Locally

1. Clone the repository.
2. Open the project directory.
3. Run:

```bash
./mvnw spring-boot:run
```

4. Open `http://localhost:8080` in your browser.

## Testing

Run the automated tests:

```bash
./mvnw test
```
